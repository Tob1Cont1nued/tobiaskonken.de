Der Sortierbot

Der Sortierbot ist ein echter kleiner Spamfilter. Er rechnet hier in deinem Browser und lernt aus einem Stapel beschrifteter Briefe. Deine Aufgabe: Vergifte seine Trainingsdaten, bis er tut, was du willst. Fünf Level lang bist du der Angreifer – im sechsten wechselst du die Seite.

Ziel:

      // ziel-mail

      Farbe der Wörter: spricht für Spam · spricht für Ok. Fahr über ein Wort für seinen Einfluss.

      // trigger-mails

      // dein brief für den trainingsstapel

      0 Wörter
      Label vergibt die Prüferin

      // eingeschmuggelt

        // qualitätskontrolle

        level 6

        Ziel:

            // werkzeug 2 · auffällige wörter

            Fahr über ein Wort, um zu sehen, wo es vorkommt.

            // auswertung

            0 Briefe markiert

            // trainingsstapel · 30 briefe

              // alle level geschafft

              Du hast den Sortierbot vergiftet – und entgiftet.

              Data Poisoning ist kein Science-Fiction: Überall, wo Modelle aus Daten lernen, die nicht vollständig unter Kontrolle sind, kann jemand mitlernen lassen. Testen heißt deshalb auch: die Daten testen, nicht nur das Modell.
